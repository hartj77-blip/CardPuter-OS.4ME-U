ZeroOS simulator

This is the real ZeroShell code from ZeroOS, compiled to WebAssembly and running at the Cardputer Zero's native 320 × 170. Sensors, battery, Wi-Fi and audio are simulated until the hardware arrives.

The simulator crashed. That's a bug in ZeroOS. Report it below: the keys you pressed and the log are filled in for you. Reload the page to start again.

Found a problem?

Report a problem opens a new GitHub issue with this build, the open app, your browser and the keys you pressed already filled in. The replay link opens this page and presses the same keys again, so whoever fixes it can watch it happen. Nothing is sent until you submit the issue.
