What this is

ZeroOS is an operating system for the M5Stack Cardputer Zero: Debian Linux underneath, with a home screen made for its 320 × 170 screen and keyboard. No mouse, no touch: everything is done from the keys. This page runs the same code as the device, with pretend hardware (battery, Wi-Fi, sensors and sound are made up).

1. Turn it on

The power switch is the red slider at the top right, above tab. Slide it right for on, left for off. Off and on again starts fresh, like the real thing.

2. Two ways to type

  • Your computer's keyboard works like a USB keyboard plugged into the Cardputer: arrows, Esc, Tab, Enter, Shift and Ctrl all do what they do on the device.
  • The keys on the device behave like the real ones. The Cardputer has no arrow keys of its own: arrows are fn with F Z X C.

shift, fn and sym don't need holding. Tap one and it applies to the next key (its light blinks). Tap twice to lock it on (fast blink), and tap again to unlock. Hold it and it stays on while held. Orange labels need fn, blue ones need sym.

3. The home screen

Home is a search box, seven pinned apps and the apps you opened last.

  • Type to search apps, settings and actions: wifi, bright, mute. Enter opens the first result.
  • 1 to 7 open the pinned apps.
  • Tab lists every app, A to Z.

5. Get more apps

ZeroOS comes with the basics (Settings, which has Wi-Fi and Bluetooth in it, Update and Apps). Everything else is installed from the Apps app: type apps on the home screen, pick one, press Enter. The Apps tab above lists what's there. In this simulator the store is pretend, but every app is already built in to try: type its name on the home screen.

6. Keep it up to date

The Update app checks for a new ZeroOS, downloads it, checks it and installs it, and goes back to the old one if something fails.

Files and notes you make here live in this browser tab only. Put ZeroOS on a real Cardputer Zero.

Built into ZeroOS

Settings (Wi-Fi and Bluetooth are sections of it), Update and Apps (the store) are part of ZeroOS itself and can't be removed.

The apps' code is in CardPuter-Apps.4ME-U. Each one has its own guide there.

Found a problem?

Report a problem opens a new GitHub issue with this build, the open app, your browser, ZeroOS's log and a replay link already filled in. The replay link opens this page and presses the same keys again, at the same speed, so whoever fixes it can watch it happen. Nothing is sent until you submit the issue.

Build __ZS_COMMIT__. If it happened on a real Cardputer Zero, open an issue and say which version you're on (cat /etc/zeroos-release).
